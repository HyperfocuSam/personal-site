# 給看不了行事曆的人的行事曆

我有嚴重的 ADHD。清單一長就當機。行事曆打開，看到的不是日程，是一面「你已經遲了」的牆。試過的每個 todo app 都要先選 project、priority、tag、時間，才讓我把那件事寫下來。結果那件事就沒有寫下來。

兩星期前我做了一個相反的東西，之後每天都在用。今天開源了：[Calendar for Real ADHD](https://github.com/HyperfocuSam/calendar-for-real-adhd)。

![記一張卡，它飄起來，做完劃掉](/images/blog/calendar-for-real-adhd-demo.gif)

## 它是甚麼

一頁白紙，中間一個 LOG 掣。打字，選日期，沒有其他問題。那件事變成一張卡片，在掣的上方慢慢飄。紅色是一星期內，黑色是這個月，灰色是還未到。做完劃掉，它自己離開頁面。

三個分頁，讓活動、提醒和死線不會疊在一起。功能清單到此為止。沒有搜尋、沒有標籤、沒有同步、沒有帳戶。

## 為甚麼要飄

一個靜止的任務格子看起來是一疊，一疊看起來是債。會動幾個像素的卡片永遠不像一張清單。頁面大部分時間是空的，這是刻意的。當它塞滿，那就是訊號，不是角落的紅色數字。

## 真正讓它運作的部分：由 agent 餵

我不輸入日期。我的助理每天讀一次我的真實行事曆、付款期和待辦工具，濾走重複的雜訊，只放上真正要緊的十幾個日期。它們就這樣飄過。

agent 跟的規則放在 repo 裏一個叫 AGENTS.md 的檔案，很短。一件真實的事一張卡。八十個字以內。不碰我拖過的位置。沒有在那段對話裏明確說過那張卡做完，就不准劃掉。最後一條是維持信任的那一條。

## 跑起來

一個 Node 檔，一個 HTML 檔。不用 build，零依賴，資料留在你機器上的一個 JSON 檔。

```
git clone https://github.com/HyperfocuSam/calendar-for-real-adhd
cd calendar-for-real-adhd
node server.js
```

然後把你的 agent 指向 AGENTS.md，或者用 repo 裏那個小小的 `todo` 指令。

一個工具如果在你正想寫下某件事的一刻要你做任何決定，它就會輸給那張白紙。這個只問你哪一天，別的不問。

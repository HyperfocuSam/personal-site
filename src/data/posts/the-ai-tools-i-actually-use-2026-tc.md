# 2026 年，我真正付錢用的 AI 工具

每次工作坊結束，總有人走過來問：「你自己實際用甚麼？」

以前我會直接丟一張截圖過去。但截圖會過期，三個月後同一封電郵又再出現，問同一條問題。

所以這是 2026 年的版本。不是我在企業內部教的那一套——銀行圍牆內仍然由 Copilot 起手，那套寫在[這裡](/blog/ai-tool-stack-3000-professionals)。這一篇，是我自己經營 Adaptig、寫文章、交貨給客戶時，每月實際付費使用的工具。

**利益申報：** 下面有幾條是聯盟連結，你經它們付費訂閱，我會收到佣金。我只放自己真正在用、真正在付錢的工具；沒有官方聯盟計劃的，就是普通連結。ChatGPT、Claude 這一類，坊間那些所謂「官方推薦連結」全部不是官方，我不會放。

## 留還是走，三個問題

跟我向企業客戶講的原則一樣：

1. 它能不能做到現有工具做不到的事？
2. 這個星期我真的會打開它，還是放著生塵？
3. 如果我要向一間銀行解釋這筆開支，我講不講得清楚？

過不了這三關，就走。

Manus Pro 八月離開了我的組合。n8n Cloud 七月離開（n8n 我仍然在用，只是不再付他們的主機年費）。Midjourney 很少打開，除非客戶那邊用得上。

## 每日打開的工具

**Claude / Claude Code** — 我真正賴以工作的系統。Agent、記憶、網站、客戶檔案，全部經它處理。想了解背後的架構，由[這一系列](/blog/claude-code-mastery-part-1-getting-started-tc)開始。

**Cursor** — 第二個螢幕上仍然長期開著。

**Gemini / NotebookLM** — 經常用。把一堆 PDF 變成一份講得清楚的簡報，NotebookLM 仍然是我見過最快的方法。

**Microsoft Copilot** — 企業辦公室的預設。

**Wispr Flow** — 每日使用：語音輸入，文字輸出。這是我的 ADHD 稅。這個月，Adaptig 多了一個同事，我替他加了一個座位。[試用 Flow](https://ref.wisprflow.ai/sam-wong)。

**Notion** — 客戶的工作區，以及中間那些亂糟糟的檔案。[Notion](https://www.notion.com/)。

**Superhuman** — 仍然是唯一的收件匣。經 Lenny's Product Pass 進來。

## 起貨、交貨

**Lovable** — 非工程同事若要一個能用的網頁，我用這個。周大福團隊試過，半小時內由簡報做到可點擊的原型。Adaptig 自己也有項目放在上面。[Lovable](https://lovable.dev/)。

**Replit** — 我有真正的應用程式放在上面，不是實驗品。[Replit](https://replit.com/)。

**Firecrawl** — 我付的是 Hobby 方案，每月 $19，有收據為證。如果你靠爬蟲吃飯，這是我真心會推薦的一個。[Firecrawl](https://firecrawl.link/sam-wong)。（順帶一提，8 月 13 日信用卡扣款失敗——那是我的問題，不是對產品的評價。）

**n8n** — €240 的年費到期之前，我取消了 Cloud 訂閱。但 n8n 我仍然在用，只是自己管。[n8n](https://n8n.io/)。

**Railway** — 我真正部署上線的地方。[Railway](https://railway.com/)。

## 讓作品被看見

**[Gamma](https://try.gamma.app/rnpecucowtbn)** — 簡報的初稿，永遠由這裡開始。

**[ElevenLabs](https://try.elevenlabs.io/2qk2r619xoll)** — 做示範，以及偶爾為客戶解說配音。

**HeyGen** — 這個月的 API 點數還在消耗中。[HeyGen](https://www.heygen.com/)。

**Canva** — 非技術團隊仍然常用。[Canva](https://www.canva.com/)。

**Midjourney** — 我付過 Pro 方案。現在只用來做 mood board，而且只在有需要的時候。

**Mobbin** — 找介面參考時仍然會開。

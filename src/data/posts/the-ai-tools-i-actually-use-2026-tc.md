# 2026 年我真正在用的 AI 工具

工作坊結束後，總有人問我「你自己用哪一套」。以前我會丟一張截圖。截圖會過期，同一封電子郵件又再來問。

這是 2026 年的版本。不是我在企業內部教的那一套——銀行牆內仍然由 Copilot 起手，那篇寫在[這裡](/blog/ai-tool-stack-3000-professionals)。這篇是我自己辦 Adaptig、寫字、出貨時，真正付費使用的工具。

## 留不留，三個問題

與我在企業內部教的一樣：

1. 它是否做到現有工具做不到的事？
2. 這個星期是否真的會打開，而不是「以後再說」？
3. 數據故事，我能否向一間銀行講得清楚？

過不了就走。Manus Pro 八月離開。n8n Cloud 七月離開（n8n 我還在用，只是不再付他們的主機年費）。Midjourney 退居備用，除非客戶辦公室需要。

## 每日在用

**Claude / Claude Code** — 我真正工作的系統。Agent、記憶、網站、客戶檔案。想看架構，由[這系列](/blog/claude-code-mastery-part-1-getting-started-tc)開始。

**Cursor** — 第二個螢幕仍然開著。

**Gemini / NotebookLM** — 常用。一堆 PDF 變成一份講得清楚的簡報，NotebookLM 仍然是我見過最快的。

**Microsoft Copilot** — 企業辦公室的預設。

**Wispr Flow** — 每日使用：語音輸入、文字輸出。ADHD 稅。這個月加了一個同事到 Adaptig 的座位。[試 Flow](https://wisprflow.ai/)。

**Notion** — 客戶工作區與中間那些雜亂檔案。[Notion](https://www.notion.com/)。

**Superhuman** — 仍然是收件匣。經 Lenny's Product Pass 進來。

## 起貨、出貨

**Lovable** — 辦公室裡非工程人員要一頁真的跑得起來，我用這個。周大福團隊試過半小時由簡報做到原型。Adaptig 自己都有項目在上面。[Lovable](https://lovable.dev/)。

**Replit** — 我有真的應用程式放在上面。[Replit](https://replit.com/)。

**Firecrawl** — 我付 Hobby 方案，每月 $19，有收據。你靠爬蟲吃飯，這是我會真心推薦的那一個。[Firecrawl](https://www.firecrawl.dev/)。（8 月 13 日信用卡扣款失敗——那是我的問題，不是產品評價。）

**n8n** — €240 年費到期之前我取消了 Cloud。我還在用 n8n。[n8n](https://n8n.io/)。

**Railway** — 我真正部署上線的地方。[Railway](https://railway.com/)。

## 讓人看見

**[Gamma](https://try.gamma.app/rnpecucowtbn)** — 簡報初稿，由這裡開始。

**[ElevenLabs](https://try.elevenlabs.io/2qk2r619xoll)** — 示範與偶爾的客戶解說配音。

**HeyGen** — 這個月 API 點數還在消耗。[HeyGen](https://www.heygen.com/)。

**Canva** — 辦公室裡還在用，尤其非技術團隊。[Canva](https://www.canva.com/)。

**Midjourney** — 我付過 Pro。只做 mood board，而且只在辦公室需要的時候。

**Mobbin** — 介面參考還在用。

## 想要工作坊那一版

我教的工具組合，比我付費使用的組合更精簡。銀行用 Copilot。設計辦公室用 NotebookLM，加一個圖像工具，加 Lovable。我寧願教深三樣，好過十樣當導覽。

想把這套帶入你的辦公室，[約時間](/zh/book/)。只想要連結，上面已經有。

工具一換，我會改這一頁。2025 那張截圖，退休了。
